# Aqua Premium Foods — B2B redesign

Redesign concept for [aquapremiumfoods.com/b2b](https://www.aquapremiumfoods.com/b2b) — HACCP-certified canned & frozen foods (Cairo · Dubai).

Built on the same structure, layout system and motion language as the Frosty Foods redesign, re-skinned to the Aqua Premium packaging palette (navy + aqua + amber).

- Bilingual EN / AR (full RTL), single static `index.html`
- Floating product-shelf hero, 24-SKU catalogue with search, filters and spec-sheet modal
- "By channel" range planner, partnership pillars, Cairo + Dubai export map
- Two-step wholesale request form (opens a structured email to info@pureibs.com)

Real product pack shots, logo and content from the current site. Rebuild: `node tools/build.js`.
